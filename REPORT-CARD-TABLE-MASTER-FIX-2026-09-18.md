# PRO-MARK 4.0.0 — Report Card Master Table Fix

## Scope
Report cards only.

## Fixed table order
### Term 3
1. SUBJECT
2. OPENER
3. END TERM
4. AVERAGE
5. GRADE
6. TEACHER
7. COMMENT

### Terms 1–2
1. SUBJECT
2. OPENER
3. MID TERM
4. END TERM
5. AVERAGE
6. GRADE
7. TEACHER
8. COMMENT

## Layout protection
- Every column is assigned an explicit fixed width.
- Every row draws each cell as its own rectangle.
- Teacher text is confined to the TEACHER cell and cannot flow into GRADE.
- Teacher name and initials are rendered inside the TEACHER cell.
- COMMENT has its own dedicated cell.
- The final column is reconciled to the exact A4 printable width.
- Existing automatic short subject remarks remain generated by the report engine.

No other portal module was intentionally changed by this fix.
