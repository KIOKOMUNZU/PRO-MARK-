# PRO-MARK 3.9.9 — Merit, Branding, Identity & Mobile Polish

## Root fixes
- Fixed Merit PDF crash caused by reading `doc.page.width` while `autoFirstPage:false` left `doc.page` null.
- Merit PDF starts on its real first page and only creates continuation pages when required; no deliberate blank page.
- Merit/class/mark/report PDFs use stronger document grid lines and a subtle PRO-MARK logo watermark.
- Official document footers include the PRO-MARK contact email `sammunzu21@gmail.com`.
- Learner lists in the dashboard and Class Lists are sorted A–Z by surname, then first/middle name.
- General / School Identity now includes an editable School Name field. The name update is transactional with the identity settings.
- Portal styling has stronger, crisper borders, blue/green/gold accents, improved cards, forms and mobile touch targets.
- Existing scrolling school announcements remain supported and are visually strengthened.
- Admission-number import behavior remains blank/null for missing values; no synthetic `IMPORT-*` numbers are generated by the corrected importer.
