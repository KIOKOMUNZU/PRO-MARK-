# PRO-MARK 4.0.0 — Portal Navigation Cleanup

## Purpose
Reduce portal complexity by making the numbered 1–24 School Management Centre the single master navigation.

## Changes
- Removed the duplicate "School Operations & Complete Workflow" shortcut panel.
- Removed duplicate People-header shortcuts for teacher assignments and class lists.
- Removed the duplicate User & Role Control shortcut to teacher assignments.
- Consolidated Teacher Assignments into one visible control centre instead of two assignment forms plus a separate manager.
- Kept the exact 1–24 master module names/order intact.
- Kept existing backend routes/data workflows intact; this cleanup does not delete school data.
- Removed only obsolete client-side shortcut handlers associated with the deleted duplicate buttons.

## Result
The portal now has one primary numbered navigation layer. Operational pages remain connected to their existing data and workflows.
